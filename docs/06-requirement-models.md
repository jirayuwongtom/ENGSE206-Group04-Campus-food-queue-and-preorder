## 2. Acceptance Criteria

### AC-01 —  การล็อกสิทธิ์การยกเลิกตามกฎธุรกิจ (BR-CFQP-01)

- Given : ออเดอร์หมายเลข #1002 ของลูกค้า A มีสถานะการปรุงอาหารในระบบเป็น "กำลังทำ" (Cooking)
- When : ลูกค้า A พยายามส่งคำขอยกเลิกออเดอร์นั้นผ่านทางหน้าระบบฝั่งผู้ใช้งาน
- Then : ระบบจะต้องปฏิเสธคำขอยกเลิกของลูกค้า โดยจะไม่อนุมัติให้เปลี่ยนสถานะ และแสดงข้อความแจ้งเตือนสีแดงสังเกตชัดเจนว่า "ไม่สามารถยกเลิกคำสั่งซื้อได้เนื่องจากร้านค้าได้ลงมือปรุงอาหารแล้ว" และสถานะในฝั่งพนักงานร้านยังคงเป็น "กำลังทำ" อย่างต่อเนื่อง

### AC-02 —  การเรียงลำดับออเดอร์ตามเวลาที่ได้รับจริง (FR-CFQP-04)

- Given : ในระบบมีออเดอร์ที่สั่งและชำระจำลองเสร็จสิ้นค้างอยู่ 2 รายการ ได้แก่ ออเดอร์หมายเลข #101 (ข้าวมันไก่ต้ม สั่งเวลา 12:00 น.) และออเดอร์หมายเลข #102 (ข้าวขาหมู สั่งเวลา 12:02 น.)
- When : พนักงานร้านค้าทำการเรียกดูรายการคิวบนหน้าจอระบบควบคุมหลักของร้านค้า
- Then : ระบบต้องจัดแสดงรายการออเดอร์ #101 ไว้ที่ส่วนบนสุดของตารางในสถานะ "ออเดอร์ใหม่" และแสดงรายการออเดอร์ #102 อยู่ในลำดับถัดลงมาอย่างถูกต้องตามกฎการเรียงลำดับก่อน-หลัง โดยไม่มีความผิดเพี้ยน

### AC-03 —  การระงับการสั่งเมนูที่ไม่มีวัตถุดิบปรุง (FR-CFQP-05)

- Given : รายการอาหาร "ข้าวมันไก่ทอด" ถูกระบุในระบบว่าพร้อมจำหน่าย และยังเปิดรับคำสั่งซื้อปกติ
- When : เจ้าของร้านทำการกดอัปเดตหรือเปลี่ยนค่าในหน้าจอควบคุมเพื่อระงับบริการเมนู "ข้าวมันไก่ทอด" เนื่องจากวัตถุดิบหมดระหว่างวัน
- Then : ระบบจะต้องประมวลผลและอัปเดตข้อมูลเพื่อให้มีผลบังคับใช้ในระบบฝั่งลูกค้าภายในเวลา 3 วินาที โดยเมนู "ข้าวมันไก่ทอด" จะต้องเปลี่ยนสถานะเป็น "ของหมด (Out of Stock)" และไม่เปิดให้ลูกค้าทุกคนสามารถกดยืนยันสั่งเมนูนี้เข้าสู่ระบบคิวได้อีกจนกว่าจะอัปเดตกลับมาจำหน่ายใหม่

### AC-04 —   การเข้าถึงรายงานสถิติความหนาแน่นคิว (FR-CFQP-06)
- Given : ระบบได้บันทึกข้อมูลและจำนวนคิวที่เกิดขึ้นในช่วงพักเที่ยงของแต่ละร้านค้าสะสมเป็นเวลา 1 สัปดาห์
- When : ผู้ดูแลพื้นที่อาหารทำการเข้าสู่ระบบฝั่งแอดมินและกดเลือกเรียกดูรายงาน "สถิติความหนาแน่นคิวตามช่วงเวลา" ของเดือนปัจจุบัน
- Then : ระบบต้องแสดงผลกราฟหรือตารางแจกแจงปริมาณคิวและเวลารอเฉลี่ยรายชั่วโมงได้อย่างถูกต้อง โดยชี้ชัดว่าช่วงเวลาใดมีความหนาแน่นสูงสุด เพื่อให้ผู้ดูแลสามารถนำข้อมูลนี้ไปพิมพ์หรือส่งออกสำหรับบริหารจัดการพื้นที่ล่วงหน้าได้
