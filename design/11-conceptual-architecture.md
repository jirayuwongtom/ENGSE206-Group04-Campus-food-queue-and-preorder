| --- | --- | --- | --- | --- | --- |
| Mobile Application | หน้าหมายเลขคิว สถานะอาหาร ปุ่มคำขอยกเลิก เปลี่ยนสถานะออเดอร์ รายงานความหนาแน่นของคิว| Mobile App | โทรศัพท์ของผู้ใช้ · ผู้ใช้ควบคุม | ไม่เก็บข้อมูลถาวร | API Application (เรียก API ค้นหา หมายเลขคิว ตัดสินเปลี่ยนสถานะออเดอร์ ดูสถานะ ด้วย REST/JSON HTTPS)|

| Database | แหล่งข้อมูลหลักของคำสั่งซื้อและสถานะคิวตาม DR-01 ถึง DR-05| ฐานข้อมูลเชิงสัมพันธ์ · MySQL + PostgreSQL| Server ฐานข้อมูล · ทีมควบคุม | ข้อมูล DR-01 ถึง DR-05 ทั้งหมด| API Application เท่านั้น|
