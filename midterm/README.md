# เทมเพลตงานสอบกลุ่ม ENGSE206

โฟลเดอร์ `midterm/` นี้มีไฟล์เปล่า 4 ไฟล์สำหรับงานสอบกลางภาค (งานกลุ่ม)

## วิธีใช้
1. คัดลอกทั้งโฟลเดอร์ `midterm/` ไปวางที่ราก repo ของกลุ่ม
2. กรอกหัวข้อ (กลุ่ม / case / สมาชิก) ในทุกไฟล์ให้ครบก่อนเริ่ม
3. ทำงานตามขั้นตอนในเอกสาร "ขั้นตอนส่งงานสอบกลุ่ม"

## ไฟล์ในโฟลเดอร์
- `twist.md` — ไฟล์หลัก: frame, stakeholder, evidence, backlog ของ Core + Mini twist
- `ai-transcript.md` — บทสนทนากับ Gemini ทั้งหมด
- `ai-use-log.md` — บันทึกการใช้ AI + การตรวจสอบของมนุษย์
- `worklog.md` — ใครทำอะไร + peer contribution

> อย่านำไฟล์เหล่านี้ไปปนกับ `evidence/week-xx/` หรือ `docs/` ที่เป็นงาน Lab เดิม
